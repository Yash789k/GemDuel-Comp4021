Evidence and reproducibility

Run npm test from the project root. Browser testing is optional: see README.html for Playwright setup. The tests create temporary accounts/data outside the real data directory and remove them afterward. Browser screenshots and the JSON report go into test-output/, which is excluded from the deliverable ZIP.

The browser script only observes server state for assertions and choosing a direction; all movement uses real keyboard events. It does not set scores/positions or invoke any test endpoints. Simulation unit tests construct fixtures directly in Node, without exposing debug APIs.

Limits of this evidence

Only modern Chrome was used for browser automation. Cross-device LAN play, other browser engines, long-duration load tests and physical speaker output were not manually tested. Fire/power-up timing and uncommon draw/deadline outcomes were checked with deterministic simulation tests. Sessions are intentionally in-memory and live matches end on a restart. The game is a local/LAN, single-process coursework prototype, not a deployed service.
