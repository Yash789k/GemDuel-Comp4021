# GemDuel-Comp4021

Gem Rush Duel is a real-time, two-player browser game for COMP4021.

With Node.js 22 or later, run these commands from the repository root.

```sh
npm install
node game_server.js
```

Open [localhost:8000](http://localhost:8000) in two independent browser sessions, sign in with different accounts, and select **Find a Match**. Run `npm test` for the automated checks. See the [project guide](README.html) for game rules and controls.
